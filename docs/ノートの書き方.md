# 解き方ノートの書き方（v1.0〜）

ノートは `src/content/notes/<分野ID>.json` に書く。形は `src/types.ts` の `Note`、検査は `src/lib/validate.ts` の `validateNote`。

## いちばん大事な方針

使う人は **SPIがほぼ初めてで、数学が不安** な就活生。スマホで読む。

1. **抽象的な式の説明をしない。具体的な数字の例題で見せる。**
   - ✗「濃度 = 食塩 ÷ 食塩水 × 100 を使い、食塩の量を求める」
   - ○「300g の食塩水に食塩が 12g → 12 ÷ 300 = 0.04 → 4%」
2. **1つの文は短く。1ステップ = 1〜2文 + 計算式1行。**
   - 計算は `calc` に分けて書く（画面で目立つ帯になる）。`text` には「なぜその計算をするか」だけを書く。
3. **図を使う。** 型ごとの例題には、できるだけ `figure` を1つ付ける（下の表を参考に）。
4. **専門用語は使ったらすぐ説明する。**（例:「余事象（＝反対の場合）」）
5. 文体は「です・ます調」。例題の問題文（stem）だけはSPI風の「である調」。

## 形

```jsonc
{
  "topic": "nv-ratio",
  "summary": "2〜3文。この分野で何が聞かれるか。",
  "keyPoints": ["最初に覚えること（1行）", "2〜4個"],
  "formulas": [
    { "label": "割合の基本", "body": "比べる量 = もとにする量 × 割合", "example": "80人の25% → 80 × 0.25 = 20人" }
  ],
  "patterns": [
    {
      "title": "型の名前（短く）",
      "lead": "どんな問題か1文",
      "example": {
        "stem": "例題の問題文（である調、具体的な数字）",
        "figure": { "type": "tape", "rows": [ ... ] },
        "steps": [
          { "text": "なぜその計算をするか（1〜2文）", "calc": "300 × 0.04 = 12g" },
          { "text": "…", "calc": "…", "figure": { ... } }
        ],
        "answer": "12g"
      },
      "point": "この型のコツ1文（任意）"
    }
  ],
  "pitfalls": [
    { "wrong": "✗ よくある間違い（具体的に）", "right": "○ 正しい考え方" }
  ]
}
```

- `patterns` は2つ以上（目安3〜6）。**型ごとに必ず具体的な数字の例題**をつける。
- `steps` は2つ以上。途中の計算を省略しない（約分・単位換算も1ステップ）。
- 例題の数字は必ず正しいこと（計算を確かめる）。分数は `{{3/5}}`、改行は `\n`。
- `wrong` / `right` には「✗」「○」の記号を書かない（画面で付く）。

## 図（figure）の種類

| type | 使いどころ | 例 |
|---|---|---|
| `tape` | 全体と部分（割合・比・損益・割引・分割払い・精算） | 定価 = [原価 2,000円][利益 400円] |
| `venn2` | 2つの集合 | A だけ 18 / 両方 4 / B だけ 14 / どちらでもない 4 |
| `line` | 道のり・時刻・旅人算・数の大小 | P(9:10) ──25分── Q |
| `flow` | 混ぜる・順にかける（食塩水、確率） | [7% 300g] + [6% 200g] = [? 500g] |
| `tree` | 樹形図（場合の数・確率、3段まで） | A─B, A─C … |
| `table` | 表（表の読み取り・3つの集合・推論の場合分け） | highlight で注目のマスを強調 |
| `slots` | 枠を横に並べる（推論の順位・座席、文の並べ替え） | [1位 P][2位 ?][3位 Q] |

`tone` は色の役割: `base`（青・基本）、`accent`（強調）、`ok`（緑・正解/求める値）、`ng`（赤・注意）、`warn`（橙）、`muted`（灰・分からない部分）。

### 例

```jsonc
// テープ図: 原価 2,000円 に 2割 の利益を見込んだ定価
{ "type": "tape", "rows": [
  { "label": "定価", "segments": [
    { "text": "原価 2,000円", "size": 10, "tone": "base" },
    { "text": "利益 400円", "size": 2, "tone": "ok" }
  ], "total": "2,400円" }
] }

// ベン図
{ "type": "venn2", "labels": ["朝食", "自炊"], "onlyA": "18人", "both": "4人", "onlyB": "14人", "outside": "4人", "total": "全体 40人" }

// 道のり（at は位置。数の大小で左右が決まる）
{ "type": "line", "points": [ { "at": 0, "label": "P", "sub": "9:10" }, { "at": 1250, "label": "Q", "sub": "9:35" } ],
  "spans": [ { "from": 0, "to": 1250, "text": "1,250m（分速50m → 25分）", "tone": "base" } ] }

// 食塩水を混ぜる
{ "type": "flow", "items": [
  { "title": "7%", "lines": ["300g", "食塩 21g"] }, "+",
  { "title": "6%", "lines": ["200g", "食塩 12g"] }, "=",
  { "title": "?%", "lines": ["500g", "食塩 33g"], "tone": "ok" }
] }

// 樹形図
{ "type": "tree", "nodes": [
  { "label": "A", "children": [ { "label": "B" }, { "label": "C" } ] },
  { "label": "B", "children": [ { "label": "A" }, { "label": "C" } ] }
] }

// 枠の並び
{ "type": "slots", "rows": [ { "label": "①", "cells": [
  { "head": "1位", "text": "P", "tone": "ok" }, { "head": "2位", "text": "S" }, { "head": "3位", "text": "Q" }, { "head": "4位", "text": "R" }
] } ] }
```

## 書いたあとに

- `npx vitest run src/content` でノートの検査を通す。
- 例題を自分で解き直して、数字と答えが合っているか確かめる。
