# Claude.ai で問題を作ってアプリに追加する

アプリに入っている問題だけでは足りないときに、Claude.ai（無料）で問題を作って取り込む手順です。API は使わないので費用はかかりません。

## 手順

1. 下の「依頼文」をコピーし、`【 】` の部分を書きかえて Claude.ai に貼り付ける
2. 返ってきた JSON（`[` から `]` まで）をコピーする
3. アプリの **設定 → 問題の追加** に貼り付けて「検査する」を押す
4. エラーがなければ取り込む。エラーが出たら、その内容を Claude.ai に伝えて直してもらう

> 取り込んだ問題は、その端末の中だけに保存されます。機種変更の前には、設定の「学習記録のバックアップ」で書き出してください（取り込んだ問題も含まれます）。

## 分野の ID

| 分野 | ID |
|---|---|
| 推論 | `nv-inference` |
| 二語の関係 | `vb-relation` |
| 語句の意味 | `vb-meaning` |

計算の問題（割合・損益算・速さ・場合の数・確率・集合など）は、アプリが数字を変えて自動で作るので追加は不要です。

## 依頼文（コピーして使う）

````
SPI（テストセンター形式）の【二語の関係】の練習問題を【10】問、オリジナルで作ってください。
市販の問題集や過去問の文章は使わないでください。

次の JSON の配列だけを出力してください（説明文は不要です）。

[
  {
    "key": "my-【分野のID】-001",
    "topic": "【分野のID】",
    "difficulty": 1,
    "format": "single",
    "stem": "問題文。改行は \\n で書く",
    "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4", "選択肢5"],
    "answer": 0,
    "hint": "解き方の方針を1文で（です・ます調）",
    "explanation": [
      "解説のステップ1",
      "解説のステップ2",
      "答え: 選択肢1"
    ]
  }
]

ルール:
- key は "my-【分野のID】-001" から連番にする
- difficulty は 1（易）〜 3（難）
- answer は正解の選択肢の番号（0 から数える）
- 正解が必ず1つに決まるようにする。二通りに解釈できる問題は作らない
- 問題文は「である調」、解説は簡潔な常体、ヒントは「です・ます調」
- 解説の最後のステップは「答え: 」のあとに正解の選択肢と完全に同じ文字列を書く
- 分数は {{3/5}} のように書く
- 正解の位置（answer の番号）がかたよらないようにする
- 二語の関係で「同じ関係のものをア、イ、ウから選びなさい」形式にするときは、choices を
  ["アだけ", "イだけ", "ウだけ", "アとイ", "アとウ", "イとウ"] にする
- 推論で「必ず正しいものはどれか」形式にするときは、choices を
  ["アだけ", "イだけ", "ウだけ", "アとイ", "アとウ", "イとウ", "アとイとウ", "必ず正しいものはない"] にする

作り終えたら、全問を自分で解き直して、正解が1つに決まるか、解説と答えが合っているかを確認してから出力してください。
````

## 注意

- 推論の問題は、作った AI が答えを間違えることがあります。取り込む前に1問ずつ自分でも解いて、正解を確かめてください。アプリに最初から入っている推論の問題は、全パターンを機械的に調べて正解を確認済みです。
- おかしな問題を見つけたら、解説の画面の「この問題おかしい？」で記録しておくと、あとでまとめて直せます。
